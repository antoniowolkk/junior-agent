# Contributing

Thanks for considering a contribution to Junior.

## Contributing a skill

If you're adding or editing a skill, see [CONTRIBUTING-SKILLS.md](CONTRIBUTING-SKILLS.md) for the
mechanical and judgment rules every skill must pass.

## General process

1. Fork the repo and create a branch off `main`.
2. Make your change.
3. Run `./scripts/validate-skills.sh` — it must pass before you open a PR.
4. Update `CHANGELOG.md` under `[Unreleased]`.
5. Open a PR using the template; fill in what changed and why.

## Reporting bugs and requesting features

Use the [issue templates](.github/ISSUE_TEMPLATE) — bug report or feature/skill request.

## Reporting a security issue

Do not open a public issue. See [SECURITY.md](SECURITY.md) for private disclosure.

## Code of conduct

Be respectful and constructive. Assume good faith. Disagreements about design are welcome;
personal attacks are not.
